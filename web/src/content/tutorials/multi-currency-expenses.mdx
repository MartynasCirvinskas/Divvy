Traveling together or splitting costs across borders? EvenJar lets every expense use whatever currency the receipt shows, and converts everything to the group's base currency behind the scenes.

## How currency conversion works

When you create a group, EvenJar records a **base currency** (for example, EUR or USD). Every expense you add is ultimately tracked in that currency so balances stay consistent for all members.

When you add an expense in a different currency — say, a restaurant bill in GBP on a trip to London — EvenJar applies the current exchange rate and stores both the original amount and the converted equivalent.

## Adding a multi-currency expense

1. Tap **Add expense** inside your group.
2. Enter the description and amount as usual.
3. Tap the **currency selector** next to the amount field.
4. Search for or scroll to the currency on the receipt (e.g. GBP, JPY, MXN).
5. Select it. The field now shows your chosen currency symbol.
6. Finish filling in who paid and how to split, then tap **Save**.

EvenJar converts the amount to the group's base currency using the exchange rate at the time you save. The converted total is shown on the expense detail screen alongside the original amount, so anyone can verify the conversion.

## Where the converted total appears

- **Expense detail** — shows both the original amount (e.g. £42.50) and the converted group-currency amount (e.g. €50.20).
- **Balances** — always displayed in the group's base currency, so the settle-up numbers are the same for everyone.
- **CSV export** — includes both columns, letting you audit the rates used for each expense.

## Tips

- Snap a photo of the receipt before converting so you have a reference for the original amount.
- If you notice a rate looks wrong, you can edit the expense and re-enter the amount; EvenJar re-converts at the current rate.
- For a recurring shared bill in a foreign currency (e.g. an international subscription), enable **Recurring** so you don't forget to log it each month.
